- 확정일: 2026-11-18

## 1. 한 줄 요약

갤럭시탭에서 S펜으로 쓴 판서가 교실 PC(TV)에 실시간으로 나타나는 전자칠판형 웹앱입니다. 빈 칠판, 이미지, PDF 위에 판서할 수 있습니다.

## 2. 사용 환경

| 구분 | 내용 |
|---|---|
| 판서 기기 | 갤럭시탭 S11 울트라(S펜), 화면 2960×1848(16:10), 가로 방향으로 사용 |
| 표시 기기 | Windows 교실 PC → 교실 TV(16:9) 또는 전자칠판 |
| 네트워크 | 태블릿은 학교 와이파이, 교실 PC는 유선 인터넷 |
| 사용 규모 | 교사 1명, 한 학급(태블릿 1대 + PC 1대) |

## 3. 범위

### 1차에 만드는 기능

| 묶음 | 기능 |
|---|---|
| 판서 | 펜, 형광펜(반투명 색), 고리 지우개, 레이저 포인터, 굵기, 색깔, 되돌리기, 다시하기 |
| 선택 | 고리로 묶은 선 옮기기, 지우기 |
| 쪽 | 쪽 추가, 이전·다음, 쪽 관리 창(순서 옮기기, 원하는 쪽으로 이동, 삭제) |
| 배경 | 칠판, 흰 판, 모눈, 줄 공책, 깍두기 공책 |
| 자료 | PDF(필요한 쪽만 골라 가져오기), 이미지·카메라 촬영(새 쪽의 배경으로) |
| 저장 | 선마다 자동 저장, 수업 파일(새로 만들기·열기), 인터넷 없이 실행 |
| 공유 | 교실 PC 보기 화면에 실시간 표시 |
| 설정 | 4자리 잠금 번호, 입력 방식, 지운 뒤 펜 복귀 |

### 만들지 않는 기능

스크롤되는 웹페이지 위 판서, 화면 영상 전송, 웹사이트를 칠판 안에 띄우는 기능, PC 화면 가져오기는 만들지 않습니다. 인터넷 자료는 캡처한 이미지를 불러오는 방식으로 다룹니다.

### 나중에 검토할 기능

양방향 판서(전자칠판에서 쓴 판서를 태블릿으로 보내기), 판서 내보내기(그림·PDF), 도형, 선택한 선의 크기 조절·복사, 칠판 위에서 옮길 수 있는 그림, 설치 파일(APK) 포장, 다른 선생님께 배포하기입니다.

## 4. 구조

코드 한 벌 안에 화면을 두 개 둡니다.

| 화면 | 주소(예정) | 쓰는 곳 | 역할 |
|---|---|---|---|
| 판서 화면 | `index.html` | 갤럭시탭(홈 화면에 설치), 필요하면 교실 PC·전자칠판 | 쓰기, 자료 불러오기, 저장 |
| 보기 화면 | `view.html#방코드` | 교실 PC(TV 출력) | 읽기 전용 전체화면 |

- 태블릿에서 '공유 켜기'를 누르면 판서가 Firebase의 수업 방을 거쳐 PC 보기 화면에 나타납니다.
- 원본(PDF·이미지 파일, 모든 판서)은 늘 태블릿 안(IndexedDB)에 있습니다.
- 수업 방에는 지금 보이는 쪽의 배경 그림과 선만 잠시 올라가고, 수업을 마치면 지워집니다.
- 교실마다 고정된 수업 방 하나를 씁니다. PC는 보기 주소를 즐겨찾기에 한 번 등록하면 매일 따로 연결하지 않습니다.

## 5. 기술 구성

| 역할 | 선택 | 고른 이유 |
|---|---|---|
| 화면 제작 | Vite + 순수 JavaScript | 칠판 화면 하나에는 React 같은 큰 틀이 필요 없고, 결과물이 가볍습니다. |
| 선 모양 | perfect-freehand 1.2.x (MIT) | 필압을 반영한 매끈한 선을 만듭니다. |
| PDF | pdfjs-dist (Apache-2.0) | 브라우저에서 PDF 쪽을 그림으로 그립니다. |
| 설치·오프라인 | vite-plugin-pwa | 홈 화면 설치와 인터넷 없는 실행을 맡습니다. |
| 태블릿 저장 | IndexedDB | 큰 PDF·이미지와 판서를 기기 안에 저장합니다. |
| 실시간 공유 | Firebase Realtime Database, 무료 Spark 요금제, 싱가포르 위치 | 쓰기 횟수 한도가 없고 결제수단 등록이 필요 없습니다. |
| 쓰기 권한 | Firebase 익명 인증 + 보안 규칙 | 수업 방에 쓰는 기기를 교사 태블릿으로 제한합니다. |
| 배포 | GitHub Pages + GitHub Actions | 배포 횟수가 넉넉하고 HTTPS 주소를 줍니다. |

### 쓰지 않는 것과 이유

| 쓰지 않는 것 | 이유 |
|---|---|
| Firestore | 무료 한도가 하루 쓰기 횟수 기준이라, 선을 실시간으로 흘려보내면 금방 소진됩니다. |
| Firebase Cloud Storage | 이제 카드 등록이 필요한 종량제(Blaze) 요금제에서만 쓸 수 있습니다. |
| Netlify 무료 플랜 | 운영 배포 한 번에 15크레딧, 월 300크레딧이라 한 달 20회 정도만 배포할 수 있습니다. |
| Supabase 무료 플랜 | 1주일 동안 사용이 없으면 프로젝트가 일시정지되어 방학마다 다시 깨워야 합니다. |
| 별도 네이티브 안드로이드 앱 | 스크롤 웹페이지 위 판서를 뺐으므로 필요한 기능이 없습니다. |

## 6. 화면 설계 (스케치 기준)

### 6-1. 화면 구역

| 구역 | 들어가는 것 |
|---|---|
| 위쪽 띠 가운데 | 필수 판서 메뉴: 펜/지우개 · 레이저 · 굵기 · 색깔 · 선택 · 되돌리기 · 다시하기 |
| 가운데 | 16:9 칠판(교실 TV 화면과 같은 영역) |
| 아래쪽 띠 오른쪽 | 쪽 막대: 이전 · 현재/전체 · 다음 · 쪽 추가 · 전체화면 |
| 좌우 가장자리 가운데 | 보조 메뉴 손잡이(둘 다 같은 서랍을 엽니다) |

- 갤럭시탭 S11 울트라는 16:10이므로 16:9 칠판을 놓으면 위아래에 띠가 남고, 필수 메뉴와 쪽 막대가 그 띠에 들어갑니다.
- 띠 높이는 최소 44px로 잡습니다. 띠가 그보다 좁은 화면(16:9 PC 등)에서는 칠판을 조금 줄여 띠를 확보합니다.
- 스케치의 쪽 막대 왼쪽 X 표시는 지운 표시이므로 만들지 않습니다.

### 6-2. 버튼별 동작

| 버튼 | 동작 |
|---|---|
| 펜/지우개 | 누를 때마다 펜과 지우개가 바뀌고, 버튼 그림과 색이 지금 도구를 보여 줍니다. 지우개일 때는 칠판 테두리를 빨갛게 표시합니다. 선택·레이저 모드에서 누르면 직전에 쓰던 도구로 돌아갑니다. |
| 레이저 | 누르면 레이저 모드가 되어 펜이 지나간 길을 빨간 빛줄기로 보여 줍니다. 각 부분은 그려지고 약 1.5초 뒤 서서히 사라집니다. 굵기·색깔과 상관없이 늘 같은 모양입니다. 저장하지 않고 되돌리기 대상도 아닙니다. 다른 도구를 고를 때까지 유지되고, 다시 누르면 직전 도구로 돌아갑니다. 교실 PC에도 같은 잔상이 보입니다. |
| 지우개 | 빨간 점선 고리로 묶은 선을 손을 떼는 순간 한꺼번에 지웁니다. 선의 일부라도 고리 안에 들어오거나 고리 선에 걸치면 묶인 것으로 봅니다(선택도 같은 기준). 기본값으로 한 번 지우면 펜으로 돌아갑니다(설정에서 끌 수 있음). 지우개일 때는 지우개 버튼 옆에 ALL 버튼이 나타나며, 누르면 이 쪽의 선을 모두 지웁니다(되돌리기로 살림). |
| S펜 버튼 | 1차에서는 쓰지 않습니다. 갤럭시탭 S11의 S펜은 블루투스가 없고, 0-A 1판 시험에서 브라우저에 버튼 신호가 들어오지 않았습니다. |
| 굵기 | 네 단계(가늘게·보통·굵게·아주 굵게) 중에서 고릅니다. 기본은 '보통'이며, 굵기는 칠판 너비 기준 비율로 저장해 TV에서도 같은 굵기로 보입니다. |
| 색깔 | 흰색·검정·빨강·파랑·초록·노랑과 반투명 형광 노랑·형광 분홍 중에서 고릅니다. 형광 색은 형광펜이 되어 글씨 아래에 그려집니다. 기본 색은 칠판 배경이면 흰색, 밝은 배경이면 검정입니다. |
| 선택 | 파란 점선 고리로 묶은 선을 끌어 옮기고, 옆에 뜨는 버튼으로 지웁니다. |
| 되돌리기·다시하기 | 그리기·지우기·옮기기를 되돌립니다. 지금 보고 있는 쪽에서 한 일만 대상으로 합니다. |
| 이전·다음 | 한 쪽씩 넘깁니다. |
| 현재/전체 | 누르면 쪽 관리 창이 열립니다. 쪽 미리보기를 보며 순서를 끌어 옮기고, 원하는 쪽으로 가고, 쪽을 지웁니다. 쪽을 지울 때는 한 번 더 확인합니다. |
| 쪽 추가(+) | 지금 쪽 바로 뒤에 같은 배경의 빈 쪽을 넣습니다. |
| 전체화면 | 브라우저 주소창과 상태 표시줄을 숨깁니다. 태블릿 설치형 앱은 처음부터 전체화면으로 열리므로 주로 교실 PC·전자칠판에서 씁니다. |

### 6-3. 보조 메뉴 서랍

왼쪽·오른쪽 손잡이 어느 쪽을 눌러도 같은 서랍이 그쪽에서 열립니다. 서랍에는 다음을 둡니다.

| 묶음 | 내용 |
|---|---|
| 자료 | PDF 열기(쪽 범위 선택), 이미지 불러오기, 카메라 촬영, 배경 바꾸기 |
| 공유 | PC 공유 켜기·끄기, 보기 주소 표시와 복사, 연결 상태 |
| 수업 | 수업 파일(새로 만들기·열기·이름 바꾸기), 이 쪽 모두 지우기, 수업 종료 |
| 설정 | 4자리 잠금 번호, 지운 뒤 펜 복귀 (손가락 확대 켜기·끄기는 위쪽 띠 오른쪽 체크 상자) |

### 6-4. 교실 PC 보기 화면

- 메뉴 없이 16:9 칠판만 화면에 꽉 차게 보여 줍니다.
- 태블릿의 지금 쪽, 확대·이동 상태를 그대로 따라갑니다.
- 화면 구석에 작은 연결 상태(연결됨·다시 연결 중)를 잠깐 보여 주고 숨깁니다.
- 브라우저 규칙상 전체화면은 화면을 한 번 눌러야 켜집니다. 클릭 없이 열고 싶으면 크롬 바로가기에 키오스크(--kiosk) 옵션을 붙이는 방법을 4단계에서 안내합니다.

### 6-5. 잘못 그어지는 일 막기

- 손가락(터치)으로는 그리지 않습니다. 펜과 마우스로만 씁니다. 손가락은 두 손가락 확대·이동에만 씁니다(사용자 결정, 2026-11-19).
- 두 손가락 확대·이동은 위쪽 띠 오른쪽 '손가락 확대' 체크 상자로 끌 수 있습니다. 손바닥처럼 넓은 접촉과 펜을 쓴 직후의 접촉은 확대로 보지 않습니다.

## 7. 설계 원칙 (코드 규칙)

1. 좌표는 칠판 기준 비율(0~1, 소수 다섯째 자리)로 저장하고, 선 굵기도 칠판 너비 기준 비율로 저장합니다.
2. 칠판은 16:9로 고정합니다.
3. 캔버스는 배경층(무늬·PDF·이미지), 판서층, 진행 중 층(그리는 중인 선과 고리)으로 나눕니다. 진행 중 층은 불투명 저지연 캔버스(desynchronized, alpha: false)로 만들고, 칠판 바탕과 판서층을 복사해 둔 뒤 그리는 중인 선만 덧그립니다. 투명한 저지연 캔버스는 갤럭시탭 S11 울트라의 크롬·웨일 모두에서 칠판을 검게 가렸습니다(0-B 시험).
4. 선마다 id와 seq(그린 순서)를 붙입니다. 형광 선은 글씨 아래에 그립니다.
5. 되돌리기는 쪽마다 따로 기록합니다.
6. 선을 하나 그을 때마다 IndexedDB에 저장합니다.
7. 수업 방에는 지금 쪽의 배경 그림(압축 JPEG 또는 WebP, 긴 변 1920px 안팎)과 선만 올립니다. 원본 파일은 올리지 않습니다.
8. 수업 종료를 누르면 수업 방 자료를 지웁니다. 종료를 잊으면 다음 실행 때 지난 자료를 지웁니다.
9. 보기 주소는 추측할 수 없는 긴 방 코드로 만듭니다. 쓰기는 방을 만든 기기(익명 인증 uid)만 할 수 있도록 보안 규칙으로 막습니다.
10. 앱을 지웠다 다시 설치하면 익명 인증이 바뀌므로, 설정에 '수업 방 다시 만들기'를 두고 새 보기 주소를 보여 줍니다.
11. 저장소는 공개되므로 학교·교사·학생 개인정보를 어떤 파일에도 넣지 않습니다.
12. 화면의 모든 글자는 한국어로 쓰고, 안내 문장은 '~합니다' 체로 씁니다.
13. 펜 입력에서 필압이 0인 점은 버립니다. 펜을 떼는 순간 이 점들이 펜이 움직이던 방향으로 이어서 들어와 선 끝을 실제보다 길게 늘입니다(0-A 1판 시험에서 확인).
14. 예측 그리기(getPredictedEvents)는 기본값을 끔으로 둡니다. 켤 때도 첫 예측점 하나만 쓰고, 예측점은 저장하지 않습니다.

## 8. 데이터 구조 (초안)

### 8-1. 태블릿 안 (IndexedDB)

```text
lessons  { id, title, createdAt, updatedAt, pageIds: [pageId, ...] }
pages    { id, lessonId, bg: { type, assetId?, pdfPage? } }
strokes  { id, pageId, seq, tool: 'pen' | 'hl', color, w, sim, pts: [[x, y, 필압], ...] }   ← 선마다 한 줄, pageId로 찾음
assets   { id, kind: 'pdf' | 'image', name, blob, w?, h? }   ← 사진은 긴 변 3000px 안쪽 JPEG로 줄여 저장
meta     { key, value }   ← 지금 수업·쪽, 설정(지운 뒤 펜 복귀, 잠금 번호 해시), PC 공유 방 코드·공유 상태

bg.type: 'chalk' | 'white' | 'grid' | 'lined' | 'kkak' | 'image' | 'pdf'
```

선을 쪽 안에 배열로 두면 선이 2,000개일 때 한 줄 그을 때마다 쪽 전체를 다시 써야 하므로 따로 저장합니다. `sim`은 마우스 선(필압을 속도로 흉내 냄)인지 표시합니다. 굵기 창의 '필압 반영'을 끄면 펜 선도 필압을 0.5로 기록합니다.

### 8-2. 수업 방 (Firebase Realtime Database)

```text
rooms/{roomId}/meta                          { owner: uid, createdAt }
rooms/{roomId}/state                         { sharing, ended?, pageId, bg, view: { z, x, y }, at }   ← 태블릿이 지금 보는 쪽과 확대 상태(ended: 수업 종료)
rooms/{roomId}/pages/{pageId}/bg             { type, img? }    img: 압축 그림(data URL)
rooms/{roomId}/pages/{pageId}/strokes/{id}   { seq, tool, color, w, sim, p }   p: 점 목록을 줄인 글자 "x,y,p;..."(×10000, 필압 ×100)
rooms/{roomId}/live/{strokeId}               그리는 중인 선(0.05초 안팎마다 점을 묶어 보냄)
rooms/{roomId}/laser/{laserId}               레이저 잔상(점을 묶어 보내고, 잔상이 사라지면 지움)
```

- 쪽 순서는 올리지 않습니다. 보기 화면은 늘 태블릿이 지금 보는 쪽을 보여 주므로 순서를 바꾼 결과가 그대로 반영됩니다.
- 공유를 켤 때 지난 `pages`·`live`·`laser`를 비우고, 태블릿이 쪽을 처음 보여 줄 때 그 쪽의 배경과 선을 통째로 올린 뒤 바뀐 선만 더하고 뺍니다.
- 수업 종료는 `pages`·`live`·`laser`를 지우고 `state`를 `{ sharing: false, ended: true }`로 둡니다. `meta`는 남겨 보기 주소를 그대로 씁니다.
- 수업 방 다시 만들기는 옛 방을 통째로 지우고 새 방 코드를 만듭니다. 옛 보기 주소에는 '수업 방이 없습니다'가 보입니다.

### 8-3. 보안 규칙 (초안, 0-B와 4단계에서 다듬음)

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": "auth != null && (!data.exists() || data.child('meta/owner').val() === auth.uid)"
      }
    }
  }
}
```

해석은 다음과 같습니다.
