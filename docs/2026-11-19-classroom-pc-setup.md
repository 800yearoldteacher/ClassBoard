# 교실 PC 보기 화면 설정 안내

교실 PC(TV에 연결된 컴퓨터)에서 태블릿 판서를 보는 방법입니다. 처음 한 번만 설정하면, 그 뒤로는 PC에서 따로 조작할 일이 없습니다.

## 준비

- 교실 PC에 크롬(최신 판)이 깔려 있어야 합니다.
- 태블릿 ClassBoard 서랍의 **공유 → 보기 주소 복사**로 보기 주소를 받습니다. 주소는 다음 꼴입니다.

  ```text
  https://800yearoldteacher.github.io/ClassBoard/view.html#방코드16자리
  ```

- 보기 주소는 메신저나 메일로 PC에 옮깁니다. 이 주소를 아는 사람은 누구나 판서를 볼 수 있으므로 학생에게 알리지 않습니다.

## 방법 1. 즐겨찾기로 열기 (가장 쉬운 방법)

1. 교실 PC 크롬 주소창에 보기 주소를 붙여 넣고 엽니다.
2. 주소창 오른쪽 별표를 눌러 즐겨찾기에 등록합니다([크롬 도움말: 북마크 만들기](https://support.google.com/chrome/answer/188842)).
3. 수업할 때는 즐겨찾기를 누르고, 화면을 한 번 클릭합니다. 클릭하면 전체화면이 됩니다. 브라우저 규칙상 전체화면은 클릭이 있어야 켜집니다.

## 방법 2. 키오스크 바로가기 (클릭 없이 전체화면)

키오스크는 주소창과 탭 없이 한 화면만 꽉 채워 여는 크롬 실행 방식입니다. 바탕화면 바로가기에 옵션을 하나 붙여 만듭니다([Chromium 공식 문서: 명령줄 옵션으로 실행하기](https://www.chromium.org/developers/how-tos/run-chromium-with-flags/)).

1. 바탕화면의 크롬 아이콘을 마우스 오른쪽 단추로 누르고 **복사**한 뒤, 빈 곳에 **붙여넣기**해 바로가기를 하나 더 만듭니다.
2. 새 바로가기를 마우스 오른쪽 단추로 누르고 **속성**을 엽니다.
3. **대상** 칸 맨 끝(닫는 따옴표 뒤)에 한 칸 띄우고 다음을 덧붙입니다.

   ```text
   --kiosk "https://800yearoldteacher.github.io/ClassBoard/view.html#방코드16자리"
   ```

   다 쓰면 대상 칸은 대략 이런 모양입니다.

   ```text
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "https://800yearoldteacher.github.io/ClassBoard/view.html#방코드16자리"
   ```

4. **일반** 탭에서 바로가기 이름을 `ClassBoard 보기`로 바꾸고 **확인**을 누릅니다.
5. 열려 있는 크롬 창을 **모두 닫은 뒤** 바로가기를 두 번 누릅니다. 크롬이 이미 열려 있으면 키오스크 옵션이 무시되고 보통 창의 새 탭으로 열립니다.

### 키오스크 화면 닫기

- 키보드에서 **Alt + F4**를 누릅니다.

## PC를 켤 때 저절로 열기 (선택)

키오스크 바로가기를 시작 프로그램 폴더에 넣으면, PC를 켜고 로그인할 때 보기 화면이 저절로 열립니다([Microsoft 지원: Windows 시작 앱 구성](https://support.microsoft.com/help/4026268)).

1. 키보드에서 **Windows 키 + R**을 누르고 `shell:startup`을 입력한 뒤 **확인**을 누릅니다.
2. 열린 폴더에 위에서 만든 `ClassBoard 보기` 바로가기를 복사해 넣습니다.
3. 다음에 PC를 켤 때부터 자동으로 열립니다. 그만두려면 이 폴더에서 바로가기를 지웁니다.

## 화면에 보이는 안내

| PC 화면 안내 | 뜻 | 할 일 |
|---|---|---|
| 태블릿에서 PC 공유를 켜면 판서가 여기에 나타납니다. | 아직 한 번도 공유하지 않은 방입니다. | 태블릿 서랍에서 **PC 공유**를 켭니다. |
| PC 공유가 꺼져 있습니다. | 태블릿에서 공유를 껐습니다. | 태블릿에서 다시 켜면 바로 따라옵니다. |
| 수업이 끝났습니다. | 태블릿에서 **수업 종료**를 눌러 올린 자료를 지웠습니다. | 다음 수업에서 공유를 켜면 바로 따라옵니다. PC는 그대로 두어도 됩니다. |
| 이 보기 주소의 수업 방이 없습니다. | 태블릿에서 **수업 방 다시 만들기**를 해 주소가 바뀌었습니다. | 태블릿에서 새 보기 주소를 받아 즐겨찾기와 키오스크 바로가기를 고칩니다. |
| 오른쪽 아래 '다시 연결 중' | PC 인터넷이 잠깐 끊겼습니다. | 연결이 돌아오면 저절로 다시 맞춰집니다. |

## 학교 PC에서 주의할 점

- **복원 프로그램:** 학교 PC에 재부팅하면 처음 상태로 돌아가는 복원 프로그램이 깔려 있으면, 즐겨찾기·바로가기가 다음 날 사라질 수 있습니다. 이때는 정보 담당 선생님께 복원 예외 설정을 부탁하거나, 보기 주소를 메신저에 남겨 두고 매일 엽니다.
- **화면 꺼짐:** 보기 화면은 클릭한 뒤 화면 꺼짐을 막도록 요청합니다. 그래도 꺼지면 Windows 전원 설정에서 화면 끄기 시간을 늘립니다.
- **주소가 바뀌는 때:** 태블릿에서 앱을 지웠다 다시 설치하거나 **설정 → 수업 방 다시 만들기**를 누르면 보기 주소가 바뀝니다. 그 밖에는 주소가 그대로입니다.
